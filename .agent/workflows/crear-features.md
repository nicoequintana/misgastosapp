# crear-feature
Crear una feature MERN completa, bien estructurada y componetizada.

1) Confirmar: nombre de feature, entidades, endpoints, pantallas y permisos.
2) Backend:
   - routes + controller + service + repository + model (si aplica)
   - validación de inputs + errores tipados
3) Frontend:
   - feature screen + componentes ui reutilizables
   - service API + hook de la feature (useNombreFeature)
4) Integración:
   - contratos request/response consistentes
   - manejo de loading/error/empty states
5) Entrega final con:
   - árbol de archivos propuesto
   - código
   - ejemplos de uso
